# Train Ticketing System

A console-based Train Ticketing System developed in **C**. The system demonstrates fundamental programming concepts through train schedule management, member account management, ticket booking, and staff administration.

## Project Overview

The Train Ticketing System provides a menu-driven interface for staff and members to manage train services and ticket reservations. It uses structured data, functions, input validation, and file handling to support the main operations.

This project was developed collaboratively as a group assignment, with each team member responsible for a different system module.

## Features

### 1. Member Information Management
- Register new members with automatically generated member IDs.
- Log in to member accounts.
- View and update member profiles.
- Reset passwords and recover forgotten passwords.
- View booking history and cancel membership.
- Generate member reports for staff.

### 2. Train Schedule Management
- Add, modify, delete, and search train schedules.
- Display train routes, departure and arrival times, available seats, and ticket prices.
- Validate schedule inputs, including time and seat information.
- Generate train operation reports.

### 3. Ticket Booking
- Search for available train tickets by departure station.
- Book train tickets and view booking details.
- Modify or delete existing bookings.
- View available tickets and booking status.
- Calculate ticket payment amounts and select a payment method.

### 4. Staff Administration
- Register and log in to staff accounts.
- View staff profiles and reset passwords.
- Apply for leave.
- Access train schedule management and member reports.

## Technologies Used

- **Programming Language:** C
- **Development Concepts:** Structures, arrays, functions, pointers, conditional statements, loops, and modular programming
- **File Handling:** Text-file and binary-file processing
- **Interface:** Menu-driven command-line interface

## Getting Started

### Prerequisites

- A C compiler or compatible C IDE, such as GCC or Microsoft Visual Studio.
- Windows is recommended because the program uses Windows console commands.

### Setup

1. Clone this repository:

   ```bash
   git clone https://github.com/356Lqyu/train-ticketing-system.git
   ```

2. Navigate to the project directory:

   ```bash
   cd train-ticketing-system
   ```

3. Open `FinalProgram.c` in a compatible C IDE.

4. Resolve any compilation errors, build the program, and run it in the IDE.
